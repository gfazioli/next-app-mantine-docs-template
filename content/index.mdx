# Introduction

This is a starter for documentation sites made with [Next.js](https://nextjs.org/) (App Router),
[Mantine](https://mantine.dev/) and MDX, and nothing else: no documentation framework sits in
between. The pages are compiled by [`@next/mdx`](https://nextjs.org/docs/app/guides/mdx), the MDX
loader Next.js maintains itself, and every piece of the interface is a Mantine component.

## Features

- **Mantine all the way**: the frame is `AppShell`, the sidebar `NavLink`, the table of contents
  `TableOfContents`, the search `Spotlight`, the code blocks `CodeHighlight`, the 404 page
  `EmptyState`
- **Code highlighted at build time** with [Shiki](https://shiki.style/), in light and dark, and
  shown by Mantine's `CodeHighlight`: no highlighter is downloaded by the browser
- **Search** with [Pagefind](https://pagefind.app/), over the prerendered pages, plus a server
  search API
- **Nextra-compatible content**: the same `content/` folder, the same `_meta` files and the same
  components (`Callout`, `Cards`, `FileTree`, `Steps`, `Tabs`, `ImageZoom`), imported from
  `@/components/docs`
- **Two deploy modes**: a server build (Vercel, any Node host) or a fully static export (GitHub
  Pages), with an optional base path
- TypeScript, [Storybook](https://storybook.js.org/), [Jest](https://jestjs.io/) with
  [React Testing Library](https://testing-library.com/docs/react-testing-library/intro),
  [oxlint](https://oxc.rs/docs/guide/usage/linter), [oxfmt](https://oxc.rs/) and
  [Stylelint](https://stylelint.io/)

search settings are there.

## Scripts

| Script | What it does |
| ------ | ------------ |
| `yarn dev` | The dev server |
| `yarn build` | The production build, then the Pagefind index |
| `yarn build:static` | A static export to `out/`, with its Pagefind index |
| `yarn test` | Formatting, lint, types and Jest |
| `yarn storybook` | Storybook on port 6006 |
| `yarn analyze` | The bundle analysis |
